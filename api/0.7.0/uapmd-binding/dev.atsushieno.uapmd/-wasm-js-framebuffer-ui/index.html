WasmJsFramebufferUi

class WasmJsFramebufferUi : FramebufferUi

FramebufferUi over the C entry points.

The plugin renders on a worker, but the services it asks for arrive on the main thread: the C layer hands them over, because a worker cannot call into JavaScript that lives on the main thread.
