Augene2Integration

interface Augene2Integration : AutoCloseable

uapmd_augene2::Integration: the Augene2 project service and everything its panel presents.

Every member runs on the model thread. Requests complete asynchronously: picking, compilation and applying the result to the timeline advance in PanelRegistry.update. Imports pick files through AppModel.documentProvider, which the host must keep ticking.

This object does not keep the service alive; once the application releases it (PanelRegistry.clearRetainedPanels) every member reads empty and every request is ignored. close releases only this reference.
